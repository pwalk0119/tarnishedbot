# Limgrave guide coverage

What the guide knowledge base needs to cover. Each entry becomes one Markdown file under
`guide/entries/`, written in our own words (or CC BY-SA Fandom text pasted by hand, with
`source: fandom:<url>`). Status: `todo` → `draft` → `verified`.

Sites of grace and items are covered inside the entries they belong to, and added as we go.
